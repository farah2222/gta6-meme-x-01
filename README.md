A GTA 6 meme for the make.fun gta6-meme-x-01 bounty: "Waited 13 years for GTA 6 — called in sick for the next 13". The meme (`meme.png`) was posted on X by [@Farahshabrina22](https://x.com/Farahshabrina22/status/2123463471253889203), with the make.fun ghost worked into the scene.

## Files

- `meme.png` — the meme image
- `post-text.txt` — the exact post text
- `POST.json` — the URL of the live post on X
- `main.ts` — copies `POST.json` to the output directory

## Run

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
